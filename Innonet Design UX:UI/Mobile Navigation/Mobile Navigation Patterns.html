Implementation Guide

Pattern Comparison

Pattern Best For Pros Cons
Slide-Out Drawer 7-15 navigation items Familiar, scalable, desktop continuity Requires extra tap to access, hidden by default
Bottom Tab Bar 4-5 primary destinations Always visible, thumb-friendly, mobile-native feel Limited slots, reduces screen space
Priority+ 6-8 items, dynamic content Progressive disclosure, desktop→mobile continuity More complex responsive logic, may confuse users

Recommendation: Slide-Out Drawer

  • Best fit for Innonet — 7 primary nav items (Discover, Events, Communities, Challenges, Companies, Network, Messages) + user menu
  • Familiar pattern — Users expect hamburger menus on mobile, reducing learning curve
  • Scalable — Can easily add more nav items without layout constraints
  • Desktop continuity — Desktop horizontal nav transitions cleanly to mobile drawer
  • Accessibility — 44px minimum touch targets, keyboard navigation support, ARIA labels

Technical Implementation

Migrating Navbar.tsx to Tailwind + responsive drawer:

  • Desktop (≥768px): Keep current horizontal layout with minor Tailwind refactor
  • Mobile (<768px): Hide horizontal links, show hamburger button, implement drawer with Radix Dialog primitive
  • State management: useState for drawer open/closed
  • Animation: CSS transitions matching --duration-slow (320ms) with --ease-out
  • Dark mode: Use existing data-theme attribute, drawer inherits theme automatically
  • Icons: lucide-react already in package.json (Menu, X, icons for nav items)
  • Overlay: Semi-transparent backdrop with click-to-close
  • Body scroll lock: Prevent background scrolling when drawer is open

Code Snippets

Key responsive utilities:

  • hidden md:flex — Hide on mobile, show on desktop (horizontal nav)
  • flex md:hidden — Show on mobile, hide on desktop (hamburger button)
  • fixed inset-0 z-50 — Full-screen drawer overlay
  • transition-transform duration-[320ms] — Smooth slide-in animation
  • translate-x-[-100%] → translate-x-0 — Drawer slide animation

Accessibility Checklist

  • 44px minimum touch targets (WCAG AAA compliance)
  • aria-label on hamburger button ("Toggle menu")
  • aria-expanded state on drawer trigger
  • Keyboard support: Esc to close drawer, Tab navigation through links
  • Focus trap when drawer is open
  • Screen reader announcements for drawer state changes
  • Color contrast ratio ≥4.5:1 (WCAG AA)

Next Steps
